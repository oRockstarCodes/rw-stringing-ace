Ch 5: Operational Amplifiers

Oct 14, 202617 min read

Overview

Readings Alexander & Sadiku, Ch 5

An operational amplifier (op amp) takes the voltage difference between its two inputs, multiplies it by a very large gain, and outputs the result. With external resistors providing negative feedback, it becomes a precise building block for amplifiers, summers, buffers, and more.

Notes

Open Loop

Open loop means the op amp is used on its own, with nothing connecting the output back to either input (Figure 5.1). The output is just:

vo​=A(v+​−v−​)(5.1)

Figure 5.1: An open-loop op amp (left) and its output vs. the input difference (right).

This isn’t very useful as an amplifier, for two reasons:

  • It saturates almost instantly. A is huge (around 105), so with ±15 V supplies the output hits a rail once the inputs differ by more than 15/105=0.15 mV. Any real signal is bigger than that, so the output just sits at +15 or −15 V.
  • The gain is unreliable. A changes a lot between chips, with temperature, and with frequency, so even a tiny signal wouldn’t get a predictable gain.

Open loop is still useful as a comparator: the output tells you which input is bigger (high rail if v+​>v−​, low rail if v+​<v−​).

Negative Feedback

Negative feedback fixes the open-loop problem by connecting the output back to the inverting input (v−​), either through a resistor or a plain wire, as in the buffer in Figure 5.2.

Figure 5.2: A buffer, the simplest negative feedback circuit. The output is wired straight back to v−​.

Why it works: the op amp corrects itself

  1. Say vo​ is a bit too high which happens where there’s a larger difference between v+​−v−​ .
  2. Some of vo​ is fed back to v−​, so v−​ rises too.
  3. That makes v+​−v−​ smaller, so A(v+​−v−​) pulls vo​ back down.
  4. The same thing happens in reverse if vo​ is too low.

The output settles at whatever voltage makes v−​ almost exactly equal to v+​. That’s where the virtual short (v+​=v−​) comes from.

Buffer with A=105 and vi​=2 V

The output is wired straight to v−​, so v−​=vo​: vo​=A(vi​−vo​)⇒vo​=1+AA​vi​=100001105​(2)≈1.99998 V The inputs differ by only 2−1.99998=20 μV. In practice that’s v+​=v−​.

The gain is set by the resistors, not by A

If a fraction β of the output gets fed back to v−​, the gain of the whole circuit is:

ACL​=1+AβA​≈β1​(when Aβ≫1)(5.2)
  • ACL​: closed-loop gain, vo​/vi​ for the whole circuit with feedback connected
  • A: open-loop gain of the op amp itself
  • β: feedback factor, the fraction of vo​ that reaches v−​. For a non-inverting amp, β=R1​+Rf​R1​​

For the non-inverting amp, β1​=R1​R1​+Rf​​=1+R1​Rf​​, which is exactly its gain formula, Eq. (5.5). A cancels out, which is the whole point: A varies a lot from chip to chip and with temperature, but resistor values are precise and stable.

Positive Feedback

Positive feedback connects the output back to the non-inverting input (v+​) instead. Now the feedback pushes the output the same way it’s already going, so instead of correcting itself, the op amp runs away:

  1. Say vo​ goes up a little.
  2. Some of vo​ is fed back to v+​, so v+​ rises too.
  3. That makes v+​−v−​ bigger, so A(v+​−v−​) pushes vo​ up even more.
  4. This repeats until vo​ hits the supply rail, and it stays there.

So the output is never in between: it’s always at +Vsat​ or −Vsat​, and the virtual short (v+​=v−​) does not apply. That makes positive feedback useless for amplifying, but useful for switching circuits.

Where it’s used: the Schmitt trigger

A Schmitt trigger is a comparator with positive feedback added. The input goes to v−​, and R1​ and R2​ feed a fraction of the output back to v+​ (Figure 5.3):

Figure 5.3: An inverting Schmitt trigger (left) and its hysteresis loop (right).

Because no current flows into v+​, R1​ and R2​ form a voltage divider from the output:

v+​=βvo​,β=R1​+R2​R1​​(5.3)
  • v+​: voltage at the non-inverting input, which acts as the switching threshold
  • vo​: output voltage, either +Vsat​ or −Vsat​
  • β: fraction of the output fed back to v+​
  • R1​: resistor from v+​ to ground
  • R2​: feedback resistor, from the output to v+​

Since vo​ can only be ±Vsat​, there are two thresholds, +βVsat​ and −βVsat​. With R1​=10 kΩ, R2​=40 kΩ and ±12 V supplies, β=5010​=0.2, so the thresholds are ±2.4 V:

  • While vo​=+12 V, v+​=+2.4 V. The output only flips to −12 V once vi​ rises above +2.4 V.
  • While vo​=−12 V, v+​=−2.4 V. The output only flips back once vi​ drops below −2.4 V.

This gap between the two thresholds is called hysteresis (the loop in Figure 5.3). It’s the reason to use one: a noisy signal wobbling around a single threshold would make a plain comparator flip back and forth rapidly, but a Schmitt trigger ignores any wobble smaller than the gap.

Spotting the Feedback Type

Figure 5.4: The three possibilities. The feedback path, if there is one, is highlighted.

Output connects back to…FeedbackWhat happensCan you use v+​=v−​?
v−​ (inverting input)NegativeOutput settles at a stable valueYes
v+​ (non-inverting input)PositiveOutput runs away to a supply railNo
Nothing (open loop)NoneOutput saturates (comparator)No

Every amplifier circuit in this chapter uses negative feedback. If you can't find a path from the output back to v−​, don't assume the virtual short.

Ideal Op Amp Model

In the ideal world, op amps are a lot easier to work with. This is because you can assume A→∞, Ri​→∞, Ro​→0. This gives two rules:

  1. No current into the inputs: i+​=i−​=0
  2. Inputs are at the same voltage (virtual short): v+​=v−​ (only valid with negative feedback)

Solving method Apply the two ideal rules, then do KCL at the inverting node. Never write KCL at the output node (the op amp sources unknown current there).

Real Op Amp Model

  • Modeled as input resistance Ri​ between the inputs, and a dependent source Avd​ in series with output resistance Ro​.
  • Typical values: A≈105–108, Ri​≈106–1013 Ω, Ro​≈10–100 Ω.
  • Saturation: output can’t exceed the supplies, so VCC−​≤vo​≤VCC+​.

Try it: pick each part of the model, then switch to the ideal op amp to see where the two ideal rules come from.

Key formulas

General

vo​=Avd​=A(v+​−v−​)(5.1)
  • vo​: output voltage
  • A: open-loop gain (the op amp’s built-in gain, with no feedback)
  • vd​: differential input voltage, v+​−v−​
  • v+​: voltage at the non-inverting input
  • v−​: voltage at the inverting input

Inverting amplifier

vo​=−R1​Rf​​vi​(5.4)
  • vo​: output voltage
  • vi​: input voltage, fed through R1​ into the inverting input
  • R1​: input resistor, from vi​ to the inverting input
  • Rf​: feedback resistor, from the output back to the inverting input

Non-inverting amplifier

vo​=(1+R1​Rf​​)vi​(5.5)
  • vo​: output voltage
  • vi​: input voltage, applied directly to the non-inverting input
  • R1​: resistor from the inverting input to ground
  • Rf​: feedback resistor, from the output back to the inverting input

Voltage follower (buffer)

vo​=vi​(5.6)
  • vo​: output voltage (the output is wired straight to the inverting input)
  • vi​: input voltage, applied to the non-inverting input

Summing amplifier (inverting)

vo​=−(R1​Rf​​v1​+R2​Rf​​v2​+R3​Rf​​v3​)(5.7)
  • vo​: output voltage
  • v1​,v2​,v3​: input voltages being summed
  • R1​,R2​,R3​: input resistors, one per input, each going to the inverting input
  • Rf​: feedback resistor, from the output back to the inverting input

Difference amplifier (general)

vo​=−R1​R2​​v1​+R3​+R4​R4​​(1+R1​R2​​)v2​(5.8)

Difference amplifier (when R1​/R2​=R3​/R4​)

vo​=R1​R2​​(v2​−v1​)(5.9)
  • vo​: output voltage
  • v1​: input voltage on the inverting side
  • v2​: input voltage on the non-inverting side
  • R1​: input resistor, from v1​ to the inverting input
  • R2​: feedback resistor, from the output back to the inverting input
  • R3​: input resistor, from v2​ to the non-inverting input
  • R4​: resistor from the non-inverting input to ground

Eq. (5.8) is just superposition: the v1​ term is an inverting amp, and the v2​ term is a voltage divider (R3​, R4​) followed by a non-inverting amp. Eq. (5.9) is the special case where the ratios match.

Cascaded stages

Atotal​=A1​⋅A2​⋅A3​⋯(5.10)
  • Atotal​: overall gain of the chain (final output ÷ first input)
  • A1​,A2​,A3​,…: closed-loop gain of each individual stage

Example 1: Op amp equivalent model

Like Prob. 5.1

The equivalent model of an op amp is shown in Figure 5.5. Determine (a) the input resistance, (b) the output resistance, and (c) the voltage gain in dB.

Figure 5.5: Equivalent model for Example 1.

Read the model straight off the diagram:

  • (a) The resistance between the input terminals: Ri​=2 MΩ
  • (b) The resistance in series with the output: Ro​=50 Ω
  • (c) The open-loop gain is the number in front of vd​, so A=2×105. In decibels: AdB​=20log10​A=20log10​(2×105)=106.02 dB

Example 2: Non-ideal voltage follower

Like Prob. 5.5

The op amp in Figure 5.6 has an open-loop gain of 50,000, an input resistance of 20 kΩ, and an output resistance of 50 Ω. Find the voltage gain vo​/vi​ using the non-ideal model.

Figure 5.6: Voltage follower for Example 2.

  1. Replace the op amp with its model. Ri​ sits between v+​=vi​ and v−​=vo​, and the output is Avd​ in series with Ro​, where vd​=v+​−v−​=vi​−vo​
  2. KCL at the output node. The current through Ri​ (from vi​ to vo​) plus the current through Ro​ (from the source to vo​) must add to zero, since nothing else is connected: Ri​vi​−vo​​+Ro​A(vi​−vo​)−vo​​=0
  3. Multiply through by Ri​Ro​ and solve: vi​vo​​=Ro​+(A+1)Ri​Ro​+ARi​​=50+(50001)(20k)50+(5×104)(20k)​=0.99998

The ideal answer is exactly 1. The non-ideal model is only worth the algebra when the question asks for it, as this one does.

Example 3: Non-ideal inverting amplifier (T)

Like Prob. 5.7 (T)

The op amp in Figure 5.7 has Ri​=200 kΩ, Ro​=50 Ω, and A=200,000. Find the differential voltage vd​ and the output voltage vo​.

Figure 5.7: Inverting amplifier for Example 3.

Call the inverting-input node v1​. Since v+​=0, vd​=v+​−v−​=−v1​, and the op amp’s output source is Avd​=−Av1​.

  1. KCL at v1​ (in through 20 kΩ = out through Ri​ to ground + out through 100 kΩ): 20k2m−v1​​=200kv1​​+100kv1​−vo​​ Multiplying by 200k: 20m=13v1​−2vo​
  2. KCL at vo​ (in through 100 kΩ = out through Ro​ into the source): 100kv1​−vo​​=50vo​−(−Av1​)​ Multiplying by 100k: v1​−vo​=2000vo​+(4×108)v1​⇒v1​≈−5.0025×10−6vo​
  3. Substitute into step 1: 20m=13(−5.0025×10−6)vo​−2vo​⇒vo​≈−9.9997 mV
  4. Then v1​=(−5.0025×10−6)(−9.9997m)≈50.02 nV, so vd​=−v1​≈−50.02 nV

Check: the ideal answer is −20100​(2 mV)=−10 mV, and vd​ is tiny, so the virtual short is a very good approximation.

Example 4: Sources connected directly to the inputs

Like Prob. 5.9

Determine vo​ in the op amp circuit of Figure 5.8.

Figure 5.8: Circuit for Example 4.

Example 5: Find vo​ and io​

Like Probs. 5.13 and 5.29

Find vo​ and io​ in the circuit of Figure 5.9.

Figure 5.9: Circuit for Example 5.

  1. v+​ from the divider (no current into v+​, so the divider is unloaded): v+​=2⋅20+3030​=1.2 V
  2. Non-inverting gain, Eq. (5.5): vo​=(1+1040​)(1.2)=6 V
  3. io​ is the op amp’s output current. It splits between the 12 kΩ load and the feedback path (40 kΩ then 10 kΩ to ground): io​=12k6​+40k+10k6​=0.5 mA+0.12 mA=0.62 mA

The feedback path counts as a load too. Forgetting it is the most common mistake on io​ questions.

Example 6: T-network in the feedback (T)

Like Prob. 5.15 (T)

(a) Determine the ratio vo​/is​ for the circuit in Figure 5.10. (b) Evaluate it for R1​=10 kΩ, R2​=5 kΩ, R3​=20 kΩ.

Figure 5.10: Circuit for Example 6. Call the middle node of the T vm​.

(a)

  1. v−​=v+​=0. All of is​ flows from the v−​ node through R1​ to vm​: R1​0−vm​​=is​⇒vm​=−is​R1​
  2. KCL at vm​ (in through R1​ = out through R2​ + out through R3​): is​=R2​vm​​+R3​vm​−vo​​
  3. Solve for vo​ and substitute vm​: vo​=vm​(1+R2​R3​​)−R3​is​⇒is​vo​​=−(R1​+R3​+R2​R1​R3​​)

(b) is​vo​​=−(10k+20k+5k(10k)(20k)​)=−70 kΩ

The ratio has units of ohms because it's volts out per amp in. The T-network gives a large gain (70 kΩ) without needing any single large resistor.

Example 7: Find io​ with a resistor network on the input

Like Prob. 5.19

Determine io​ in the circuit of Figure 5.11.

Figure 5.11: Circuit for Example 7.

  1. Replace everything left of the 2 kΩ with its Thévenin equivalent (1.5 V source, 3 kΩ, 6 kΩ): Vth​=1.5⋅3+66​=1 V,Rth​=3k∥6k=2 kΩ
  2. Now it’s a plain inverting amp with an input resistance of Rth​+2k=4 kΩ. By Eq. (5.4): vo​=−48​(1)=−2 V
  3. io​ flows down through the 4 kΩ load: io​=4kvo​​=4k−2​=−0.5 mA

So 0.5 mA actually flows up through the load, into the op amp’s output.

Thévenin works here because the 2 kΩ connects to the virtual ground, so the circuit to its left sees a fixed load. Without Thévenin, you'd do KCL at the 6 kΩ node instead and get the same answer.

Example 10: Design problem

Like Prob. 5.45

Design an op amp circuit to perform vo​=2v1​−3v2​. All resistances must be ≤ 100 kΩ.

  1. Pick the circuit. One input is subtracted and one is added, so use a difference amplifier. The subtracted input (v2​) goes to the inverting side and v1​ to the non-inverting side, so v1​ and v2​ swap places compared with Eq. (5.8).
  2. Match the inverting term using Eq. (5.8): we need R1​R2​​=3. Choose R1​=20 kΩ, R2​=60 kΩ.
  3. Match the non-inverting term. The non-inverting gain is 1+R1​R2​​=4, but we only want 2, so the divider has to halve v1​ first: R3​+R4​R4​​⋅4=2⇒R3​+R4​R4​​=21​⇒R3​=R4​ Choose R3​=R4​=50 kΩ.
  4. Check: vo​=−2060​v2​+10050​(4)v1​=2v1​−3v2​ ✓, and every resistor is ≤ 100 kΩ ✓.

Figure 5.14: One possible design for Example 10. Many other resistor values work too.

Design questions have many right answers. Pick one resistor freely (here R1​), then solve for the rest from the gains.

Example 11: Difference amplifier with mismatched resistors

Like Prob. 5.47

The circuit in Figure 5.15 is a difference amplifier. Find vo​ given v1​=2 V and v2​=3 V.

Figure 5.15: Difference amplifier for Example 11.

  1. Check the ratios first: R1​/R2​=5/20=0.25 but R3​/R4​=10/30=0.33. They don’t match, so the shortcut Eq. (5.9) does not apply.
  2. v+​ from the divider: v+​=3⋅10+3030​=2.25 V=v−​

Example 12: Cascaded stages (T)

Like Prob. 5.59 (T)

In the circuit of Figure 5.16, determine the voltage gain vo​/vs​. Take R=10 kΩ.

Figure 5.16: Two cascaded stages for Example 12.

  1. Stage 1 is non-inverting (vs​ on v+​, R to ground, 3R feedback). By Eq. (5.5): A1​=vs​v1​​=1+R3R​=4
  2. Stage 2 is inverting (R in, 2R feedback). By Eq. (5.4): A2​=v1​vo​​=−R2R​=−2

Common mistakes

  • Writing KCL at the output node instead of the inverting input
  • Assuming v+​=v−​ when there’s no negative feedback (e.g. comparators)
  • Forgetting the minus sign on inverting and summing amps
  • Ignoring saturation: a “gain of 100” on 1 V with ±15 V rails gives 15 V, not 100 V
  • Mixing up R1​ and Rf​ in the non-inverting gain (1+Rf​/R1​, not R1​/Rf​)
